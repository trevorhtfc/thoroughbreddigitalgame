# Sound sources (owner, 13 Nov 2026)

The recordings `tools/sound/mix_real_sounds.py` makes the race view's sounds from. Only `galloping-pixabay.mp3` is free
to use (Pixabay's licence). The rest are clips from racing videos found online (Cheltenham, the Japan Cup, Aintree, the
Grand National finish, a view from the stalls): fine as stand-ins while the game is a free test, but **replace them with
the owner's own recordings or licensed sound before any paid or commercial release** (same names here, then run the
script again).
